# متجر اونمي — موقع إلكتروني لبيع الأجهزة الإلكترونية

موقع متجر إلكتروني متكامل (واجهة أمامية بالكامل) مبني بـ HTML / CSS / JavaScript فقط،
بدون أي اعتماد على إطار عمل خارجي، جاهز للرفع على **GitHub Pages** مباشرة.

## المحتوى

```
onemi-store/
├── index.html          الصفحة الرئيسية
├── products.html        صفحة كل المنتجات (بحث + فلترة حسب الفئة + فرز)
├── product.html          صفحة تفاصيل منتج واحد (?id=p01)
├── cart.html             سلة التسوق
├── checkout.html         إتمام الطلب (بيانات الشحن + طريقة الدفع)
├── admin.html            لوحة تحكم بسيطة لعرض الطلبات الواردة
├── css/style.css         كل التنسيقات (تصميم بهوية خاصة: أخضر لوحة الدارة + نحاسي)
├── js/products-data.js   بيانات المنتجات (عدّل هنا لإضافة/حذف منتجات)
├── js/icons.js           أيقونات SVG لكل فئة (بدون صور خارجية)
└── js/main.js            منطق السلة والعرض المشترك بين الصفحات
```

## كيف يعمل التخزين؟

الموقع ثابت (static) بالكامل، لذلك:
- **سلة التسوق** تُحفظ في `localStorage` الخاص بمتصفح الزائر.
- **الطلبات المكتملة** عبر صفحة الدفع تُحفظ أيضًا في `localStorage` ويمكن مشاهدتها
  وتصديرها كملف JSON من `admin.html`.
- لا توجد قاعدة بيانات حقيقية أو خادم خلفي في هذا الإصدار — وهذا مناسب تمامًا
  للبدء السريع والعرض، لكنه يعني أن الطلبات تبقى على جهاز الزائر نفسه فقط ولا تصل
  إليك فعليًا عبر الإنترنت.

## رفع الموقع على GitHub Pages (خطوة بخطوة)

1. أنشئ مستودع (Repository) جديد على GitHub، مثلًا باسم `onemi-store`.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع:
   ```bash
   git init
   git add .
   git commit -m "إطلاق متجر اونمي"
   git branch -M main
   git remote add origin https://github.com/USERNAME/onemi-store.git
   git push -u origin main
   ```
3. من إعدادات المستودع على GitHub: **Settings → Pages**.
4. تحت "Build and deployment" اختر **Deploy from a branch**، ثم الفرع `main`
   والمجلد `/ (root)`، ثم اضغط **Save**.
5. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بصيغة:
   `https://USERNAME.github.io/onemi-store/`

## لربط دومين خاص (مثل onemi.com)

أضف ملف باسم `CNAME` (بدون امتداد) في جذر المشروع يحتوي على الدومين فقط، مثال:
```
www.onemi.com
```
ثم أضف سجل CNAME في إعدادات الدومين يشير إلى `USERNAME.github.io`.

## كيف أضيف أو أعدّل منتجًا؟

افتح `js/products-data.js` وأضف عنصرًا جديدًا داخل مصفوفة `ONEMI_PRODUCTS`، باتباع
نفس الشكل الموجود (id فريد، الفئة، السعر، المواصفات...). لا حاجة لأي أدوات بناء —
فقط احفظ الملف وارفع التعديل (commit & push).

الفئات المتاحة حاليًا: `phones` ، `laptops` ، `headphones` ، `watches` ، `cameras` ، `accessories`.
لإضافة فئة جديدة: أضف أيقونة لها في `js/icons.js` وأضفها إلى `ONEMI_CATEGORIES`.

## لتفعيل دفع إلكتروني حقيقي واستقبال الطلبات فعليًا

هذا الإصدار عرض توضيحي لتجربة شراء كاملة من الواجهة فقط. للانتقال إلى متجر حقيقي
يستقبل طلبات ومدفوعات فعلية، ستحتاج أحد الخيارين:

1. **خدمة متجر جاهزة** (أسهل وأسرع): سلة، زد، سلة Salla، Shopify… وربط الدومين بها.
2. **خادم خلفي بسيط (Backend)**: يمكنك بناء API صغيرة (Node.js / PHP / Firebase)
   تستقبل بيانات نموذج `checkout.html` وتُرسلها إلى بوابة دفع مثل **مدى** أو
   **PayTabs** أو **Stripe**، وتخزّن الطلبات في قاعدة بيانات حقيقية بدل `localStorage`.

## التخصيص السريع

- الألوان والخطوط: كلها متغيرات CSS في أعلى ملف `css/style.css` ضمن `:root`.
- اسم المتجر وشعاره: ابحث عن `برند` / `brand-mark` في ملفات HTML.
- نصوص "من نحن" و"تواصل معنا": داخل `index.html` مباشرة.
